# MovieBook - Render Ready

A beginner-friendly movie ticket booking demo built with HTML, CSS, and JavaScript.

## Features
- Movie selection and show time selection
- Interactive seat selection and booking summary
- Demo payment screen
- Booking ID and ticket display
- Print ticket and close-window button

## Run locally
Open `index.html` in a browser.

## Render static site
- Service type: Static Site
- Build command: leave blank
- Publish directory: `.`

Note: This is a frontend demo. It does not process real payments or save bookings to a server/database.
